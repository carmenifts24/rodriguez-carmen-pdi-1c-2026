Deteccion: bordes, contornos, landmarks, medidas, plantillas y Haar.

Generacion: difusion, text-to-image, inpainting generativo, aceleracion.
Pipeline clasico recomendado Conversion de color → histograma/canales → suavizado → umbralizacion → morfologia → contornos → medicion.
MLP vs CNN MLP aplana la imagen y pierde estructura espacial. CNN conserva vecindad y aprende filtros locales. Para formas visuales, CNN es mas confiable.
venv vs Docker Entorno virtual para desarrollo individual rapido. Docker para despliegue y reproducibilidad garantizada entre maquinas.
Inpainting clasico vs generativo TELEA/NS interpolan desde el borde. Difusion genera contenido nuevo semanticamente coherente con el prompt.
